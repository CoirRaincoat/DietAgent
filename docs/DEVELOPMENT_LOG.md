- 输出规范化数据、关键词索引和含 SHA-256 的质量报告到 artifacts/。
- 数据层 9 个测试通过；补充 .gitattributes 保留原始数据字节和跨平台代码换行。
## Phase 3 Agent 核心

- 接入 DeepSeek JSON 意图解析，业务层只依赖 BaseLLM；密钥通过 .env 注入，不记录上游响应或密钥。
- 提供注册工具、全库关键词检索、有限词典过敏/禁忌筛查、菜单规划、指定换菜和可核查定性说明。
- 模型解释只选择已经验证的事实 ID，返回文本由程序构建；解释服务故障时回退到同一事实模板。
- SQLite 保存约束与菜单状态；同会话串行，已完成请求可重放；首轮 request_id 映射稳定会话 ID。
- 独立审查修复 SQLite 连接关闭、首轮重试、未明确过敏的跨轮阻断，以及解释请求意外重规划。
- 合成画像 900001 的真实 DeepSeek 三轮联调通过：推荐、只换第二道、只解释。没有读取原始健康档案或原始对话文件。
- 原始健康档案外部回放被自动审批拒绝，尚未执行；仅完成合成资料外部联调与本地数据测试，用户后续明确选择仅用合成资料联调，原始回放不执行。
