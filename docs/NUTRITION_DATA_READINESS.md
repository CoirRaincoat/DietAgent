# 低钠与护心：当前能力及定量数据依赖（2026-10-04）

当前只能按完整原方做定性偏好筛选与风险披露，不能称摄入达标、治疗效果或可靠营养量。本文记录用户新问题与数据准备，不增加求解器/评分体系，不下载新库、不外传原2000/档案/对话，也不修改原配方。10月6日冻结前不临时接未经验收的营养估算。

## 分清两个层次

2026-10-04用户补充：三小勺不等于过量，判断应看每人全天总摄入。当前原方没有勺重、份数、各人的实际食用量和全天其他来源，不能由“盐3小勺”推出高钠，也不能证明达标。含盐/生抽只是需核用量的来源，不作为硬禁忌；未写盐不等于无钠。M05中的原汤因此不凭这条描述判坏或强制换掉。日摄入满足参考限量与单道菜的低钠认定应分别显示。

可估算而非完全不能计算：WHO将盐5克近似为一茶匙。**仅假设“小勺”为此平茶匙且5人均分整锅**，3勺约15克盐、每人约3克盐（约1.2克钠）；这是该汤添加盐的情景计算，不是源勺重、真实份数或完整每日摄入。其他菜、调味品和食物中的钠仍须合计，实际少喝/剩汤/分配差异也未计入。估算及假设单列，不回写原方克数、不冒充实测或低钠认证。[WHO减钠资料](https://www.who.int/westernpacific/newsroom/fact-sheets/detail/sodium-reduction)

- 定性：保过敏/不辣/素食硬约束；依据完整食材、调味品和原做法披露盐/糖/部分脂肪来源等。不能因一项辅料出现就说整菜护心，也不能把机器蒸制或菜名清淡等同低钠。
- 定量：可靠食物成分、实际品牌调味品标签、完整用量及可食重量/生熟状态、成品份数或实际分餐，才可输出注明不确定性的估算。食物库缺值不是0，五个人不能直接默认平均吃掉五分之一。

健康饮食涉及整体模式，包括多样蔬果、豆类、全谷物及合适蛋白来源，并限制盐、游离糖、饱和与反式脂肪；不能用一道菜的辅料证明护心功效。[WHO健康饮食资料](https://www.who.int/en/news-room/fact-sheets/detail/healthy-diet)

## 最小可靠数据

### 用户补充的护心食物方向（2026-10-04，定性参考待接入）

优先鱼、豆类/豆制品，有真实去皮/瘦肉来源依据的禽肉，搭配蔬果与部分全谷物；少选加工肉、肥肉/皮、油炸和添加糖。这与AHA蛋白来源建议、NHLBI DASH的食物模式方向一致，但不是每个用户的医学食谱。[AHA蛋白来源](https://www.heart.org/en/healthy-living/healthy-eating/eat-smart/nutrition-basics/picking-healthy-proteins)、[NHLBI DASH](https://www.nhlbi.nih.gov/health/dash/living-with-dash)

实现时核原料和成菜主体，不由少量鱼/胡萝卜辅料、菜名/原健康标签把整菜升级为护心；鸡胸/去皮要有原文字，鸡肉不擅自视为去皮。各食物仍受原过敏、素食和不辣限制，鱼/豆类不是安全豁免。不把用户清单的每周次数、每日蛋/蔬果/油/坚果克数写成所有人的硬约束；份数、实际全天摄入及个体医疗需求未核。保留定量依赖，当前比赛阶段只考虑可追溯的食物选择和理由，不声称Omega-3含量或治疗效果。

1. 本地食物成分记录：食物ID、名称、来源版本、每100克可食部基准、原/熟状态、钠、能量、蛋白质、脂肪与饱和脂肪、碳水和纤维等；缺项留空。有需求再拓展其他字段，不假设所有食物都完整。
2. 实际品牌调味品：生抽/酱油/番茄酱/鸡粉/加工肉等的营养标签和配料表，钠含量单位与计量基准。复合品不能只用番茄、鸡肉等基础原料替代；需要克重，毫升要可靠密度，勺/适量不能猜。
3. 配方用量：实际食用主辅料与原步骤追加的盐糖油，去骨/去皮/可食部、生熟转化和是否弃汤/弃汁等。只计算有证据部分，不把缺调料的和当完整整菜钠。
4. 分餐：原方成品份数、实际每人食用量；多人共享要承认分配未知。份数与克数缺失时不声称每人摄入达标。

可评估本地可合法使用的食物成分资料、实际商品标签。USDA FoodData Central区分分析基础食物与制造商标签来源，且有不同份量基准；可作为候选公开数据，不是中国调味品牌的现成替代库。[FDC数据说明](https://fdc.nal.usda.gov/data-documentation/)、[基础食物与份量文档](https://fdc.nal.usda.gov/Foundation_Foods_Documentation/)。选库前核适配、版本及许可证；即使公开基础食物在线查询可用，也不授权把原2000配方或私有需求逐条发送。

## 计算与显示边界

在重量和食物匹配可靠时，用`食用克数/100 × 每100克成分`估算各食材，再合计；没有可靠食用重量/调味品/分餐时，只能标部分计算或不可判断，不能显示一个貌似完整的低钠百分比分。烹饪转化/弃汤也会使原料和与实际摄入有差异。[FDC份量文档](https://fdc.nal.usda.gov/Foundation_Foods_Documentation/)

WHO一般成人日钠参考为低于2000毫克，约相当于盐5克；这是日摄入参考，不等于一餐或食品“低钠”标签的判定，也不是给特殊疾病个体的治疗方案。[WHO减钠资料](https://www.who.int/westernpacific/newsroom/fact-sheets/detail/sodium-reduction)

不自动把日目标除三给一餐、不自行推荐替盐或医学限制；个体医疗要求需另有明确依据。就当前比赛截止，先保可追溯定性提示并清楚声明未做定量；可靠数据接入/映射/已知配方校验/独立验收属于保留的后续TODO。
