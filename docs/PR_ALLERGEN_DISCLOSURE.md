# PR标题

fix: 明确蛋清来源并补充品牌调料过敏核对提醒

# 正文

按用户要求改善实际回复中的过敏信息，不改菜单排序或原2000配方。

## 改动

- 源蛋清／蛋黄／蛋液等明确标为蛋类来源；鸡蛋过敏仍排除。植物／大豆／乳清等蛋白不在本提醒中误称蛋类，未明蛋白粉不称确定鸡蛋。
- 鸡精、鸡粉、鸡汁、香肠、豉油、生抽、蚝油等实际出现的品牌配料提示核配料表、过敏原及交叉接触，不推定某厂家配方通用。
- 提醒进入默认正文必选事实、返回warnings及既有详情reasons，模型仅选开场白也不丢；不新增接口字段或付费模型依赖。
- 普通品牌未知不新增拒绝；明确过敏命中与此前未知酱汁、素食、不辣、数量、库存、局部及身份门禁保留。提醒不等于已认证整餐安全。
- 更新基础调料自配参考，区分中式甜咸／番茄酸甜烧烤风味；不自动采用改编方或据此清除原料汁风险。
