# 一次换多个菜位，局部食材要求不扩大为整餐忌口

支持“保留第2道，第1、3道换掉”“保留明确菜名，其他两道换成别的菜，其他不要菌菇”。保留菜名只在本地当前菜单唯一对应时解析，不上传源菜单。指代“这道”不明确时澄清，不猜测。

公开自编已有菜单回放：葱烧蘑菇／菌菇蒸乳鸽／香菇鸡肉焖饭 → 蚕豆炒韭菜／菌菇蒸乳鸽／家常菜肉包子。第2道完整原方不变，第1和3道一并替换；仅这两道保存不含菌菇要求。虾过敏、不辣、3菜0汤保留。原包子90分钟发酵及品牌调味料核对提醒仍显示。初始三菌菇菜单来自先前隔离试验，不冒充默认初次推荐；冻结解析后实际默认接口执行，不是实网模型或独立评测。

- 菜位食材限制存为餐内slot_food_exclusions，不写用户档案；解释、继续、重试、重启、后续局部调整和菜单恢复均核对。明确新餐边界结束该餐菜位限制；数量变化导致旧位置失效需澄清，不悄悄丢要求。

- 本功能没有新增付费生成路径。菌菇使用原料/步骤中的有限类别词表，不作营养、健康或全部未知品牌无菌菇认证。不同菜位食材范围分别保存，未确认范围先澄清。
