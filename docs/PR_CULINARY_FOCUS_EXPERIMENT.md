# 标题

feat: 增加显式菜品主体去重实验与独立源验收（默认关闭）

# 正文

## 目的与改动

修正全食材重叠可能为减少配料重复而换掉合理成菜的实验目标。联合源声明、菜名主体与主角色，调味/黏合/浇头不等同整菜主体，完整源配方仍用于安全与定性营养检查。

- 增加显式主体实验，默认False不变，保留旧布尔实验；保护目标、角色、餐次、偏好、查询、数量与局部槽位，未知证据不获新颖奖励。
- 补有限明确食材别名和温泉蛋反例，不扩大硬约束归一化。
- 验证器v18支持独立源ID主体审核，读取被测目录观察，不接受响应自报成功；失败阻止质量观察。
- 输出同集菜单、源事实、测试集/逐项结果和空白人工笔记，更新TODO与创新点草稿。

## 验证及不接纳依据

205项专项、1689项全量通过，1条既有警告；选定4模块合计覆盖98.46%。10份源请求仅1份菜单变化，两设置各10/10有限源一致性，旧8/10失败保留。7道含2汤虽主体重复下降，两份配方仍含南瓜、明确蒸制源增加，不能证明整体搭配净收益。因此服务/API不启用。

## 边界

无质量满分、定量营养/临床效果、真实模型/TTFT或人工校准结果；不含跨餐轮换、独立留出或全库主做法分类。公共v3原字节不改、旧报告保留；私有档案/对话/密钥和原始报告不提交。仅本地提交，由用户推送合并。
