进一步读源：3变化均倾向开花馒头。原配方有面粉800克、熟紫薯片80克、熟南瓜块80克等，降压/护心各2点来自熟南瓜块的蔬菜类别参考，而主成菜仍是主食。这不是可核验的低盐/营养优势，也不能将该配料算成一道蔬菜菜位。份数/每人摄入未知，不由配方重量推临床或摄入结论。
