# 标题

feat: 试验区分类别健康排序与配料来源，并保留独立源反例

# 正文

## 变更

- 增加显式、默认关闭的类别角色限制试验，服务/API不启用。
- 类别加分要求唯一成菜角色及真实配料证据；来源、警示和其他有限目标贡献仍保留。
- 增加另行作者源审核门禁，不导入生产分类器，不以响应成功或自报正向开关证明正确。
- 导出冻结四模式菜单、逐例失败、排序轨迹、原料步骤及空白人工复核模板；更新算法TODO与创新点草稿。

## 实测

- 1991全量、230专项通过，保留1条原有Starlette警告。
- 同集10份源输入，类别贡献检查2/8→8/8，但源一致性10/10→6/10，非退步10/10→7/10；4份菜单变化，建议未变。
- 7道少一份南瓜，却丢失已知方法覆盖；6道蒸法重复增加。冷冻成品完整配方、南豆腐/米/燕麦饭映射及刷面蛋的排序问题继续暴露。
- 默认2000条×6目标轨迹及有序菜单/建议与归档一致；不把实验或测试全过宣称为质量提升。

## 边界

该候选因负结果未接纳，保持关闭。没有新API、AI/人工评分、官方私有资料或真实模型时延；没有计算五人营养摄入或证明临床适配。240项开发/源输入不是官方或独立留出集。只做本地提交，不自动推送/合并。
