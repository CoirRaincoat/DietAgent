# PR 标题

fix: 有界复核新增健康偏好，保持局部换菜并披露源关注项

# PR 正文

## 背景

旧菜单合法不等于新健康偏好已经执行；此前增肌更新仍保留旧菜，护心未配置，源步骤盐/酱料也可能遗漏。源回放另发现甜羹、肉松、粮食包馅的成菜角色错误。

## 改动

- 同角色有限复核新增健康/清淡偏好；逐目标不退步，保护硬规则、汤位、明确数量、已经覆盖食材偏好、餐次及指定槽位。
- 普通继续与解释不重新优化受保护的其他槽位，HTTP/SSE及重启覆盖；再次补充实际需求才重新复核。
- 排序和解释共享配料/原始声明/步骤证据，补护心及有限钠/糖/脂肪来源提示；增肌正向排序限蛋白质成菜位，不推算克数。
- 修复粮食成型与准备记录角色，并通过全库触发扫描补烤鸭附薄饼、叫花鸡面皮外壳的误拒边界。
- 独立源披露审核与角色反例门禁阻止失败输出进入质量观察；版本化输入、逐例事实、历史失败及创新点/TODO同步。

## 验证

- Python3.12锁定依赖：136专项/1512全量通过，1条既有依赖弃用警告。
- 新健康证据、复核及独立检查的语句/分支合计覆盖率99%；严格类型、Ruff与diff检查通过。
- 同输入与菜谱SHA的10份实际源回放：健康关注项披露3/9→9/9，另1份未请求健康目标；源身份/有限不辣/数量及普通继续分别逐例通过。
- 正餐范围仍8/10，菜单仍有甜菜误占位、南瓜同质化；未计健康实现率或质量总分。
