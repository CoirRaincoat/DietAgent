# PR标题

fix: 明确鱼菜偏好优先于辅料与含钠来源代理，并披露原方取舍

## 实际问题与修改

新编N08要求4人晚餐、5道含1汤、不辣清淡、护心/降压、鱼和豆制品。旧默认菜单没有鱼主体：燕麦南瓜泥／蒸秋季时蔬／鸡肉玉米肠／基础煮燕麦饭／日式味增汤。汤中木鱼花不算鱼主体。

同输入现仅第3道换为嫩滑蒸鱼片，其余4道完整源方与顺序不变。现有合规命名鱼/豆腐候选并非缺少；原实现的含钠来源负权与鸡肠少量胡萝卜正权阻挡明确偏好。复用既有末端有界修复，不加求解器、评分体系、扩池或详细做法。

## 边界

- 只在明确护心目标及已有源方主体支持的鱼/豆腐偏好下，允许普通含钠来源内部代理取舍；其他目标与权限边界保留。
- 保过敏、不辣、素食、菜/汤数、明确食材/做法、ID、只读、局部换菜和重试；原生、兼容及SSE说明须保留取舍事实。
- 新鱼原方盐2g、生抽10ml、白胡椒2g、20分钟腌制及设备参数缺口不改写。不宣称低钠、控压疗效、Omega-3含量或四人份量。
- 用户要求的统一证据标准见`HEALTH_ASSESSMENT_STANDARD.md`。**全局旧含钠来源扣分仍待分拆**，本PR不是全局标准迁移完成。
