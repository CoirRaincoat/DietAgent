# 标题

feat(evaluation): 隔离食材观察词表，补齐实际菜单的有限内容特征盲区

## 解决的问题

旧观察没有识别原声明的秋葵、香菇、芹菜等。清淡便当旧共同对仅6/18，不能从已识别部分相似1→1推断整餐没有内容变化。直接扩生产词表又可能影响主体角色和排序，因此先隔离观测。

## 改动与接入边界

- 新增离线有限声明特征；10家族、15精确名称，标题与步骤不补食材，调料／油／淀粉／提取物不扩展，不明肉末不推断动物。
- 内容观察显式选择 `planner_v4` 或 `observation_v1`，默认仍旧政策；同一政策内对齐两版本均有特征的菜位对，缺失不当零相似。政策变化本身不是菜单改善。
- 生产食材词表、主体角色、过敏、不辣、健康规则、原2000、官方与私有数据不改；服务不引用新观察，不默认接入排序。
- 未复制开源代码、安装依赖或新增付费调用；GitHub复用原则已入TODO，连续无净收益时再根据真实卡点查适用算法。
