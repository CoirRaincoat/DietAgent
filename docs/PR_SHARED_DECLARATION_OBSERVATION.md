## 目的与实现

源文明确的牛肉、鸭肉、糯米不能因为旧有限观察词表漏项而被当作主体未知。新增显式 `feature_policy="shared_v2"`，复用已有完整蛋白食材声明匹配，增加有限整粒谷物。黄鱼每条声明只得到一个种类特征，不额外加generic鱼权重；有另一条明确鱼声明时分别观察。
