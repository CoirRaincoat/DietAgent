## 变化与边界

新显式 `food_identity_policy="shared_source_v1"` 用共享全声明表示补鱼／虾／牛／鸭，与原有限别名取并集；声明配料和具名主菜分开。具体动物名仍需原肉鱼主体参考，有限肉丸／肉片形式可由唯一明确猪肉且不存在未明动物声明证明身份；并不证明营养或份量。主菜需独立角色、正餐资格与实际成菜方法。

植物同名、鱼香／鱼露／鸡汤／复合酱、配字后的辅菜和肉末豆腐不能伪造肉鱼主体。只有肉末／咸肉不能猜动物；有已声明猪肉也不自动消除另一条未明肉末。未知设备程序不能靠菜名补蒸。鱼汤不能跨角色当蛋白主菜；原不辣、过敏、排除、素食、汤／荤素数量、查询／来源／餐次、逐目标／原记录与局部范围门禁继续核验。

默认仍legacy，服务与shared_v2历史观察均未改变。新投影只在本策略内比较同输入前后，不用增加特征或更换分母证明质量。旧严格门禁违反、候选增加和移出都保留报告。
