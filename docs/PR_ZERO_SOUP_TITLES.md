# 修复零汤数量备注污染菜位角色

## 问题与实现

前轮正式报告中的单菜“一人食1菜0汤”被旧“标题包含汤字”规则分类为汤，导致无汤请求无法排菜。数量装饰也会遮住肉酱/绞肉等组件名称。

实现提交：`1afafd8f50e8f64983c11616020050e3f794aaea`；对照基线：`f4eaf16864239df930cdc838845340ab139c287a`。仅本地准备，未自动推送/合并。

- 真正汤菜名仍保留，不能因零汤备注将番茄汤冒充肉菜；较长数字、十进制尾数及汤匙/汤底/汤圆等词内片段不误删。
- 多菜数量保持，支持有限装饰；不能先清零汤半句而隐藏套餐单位。
- 组件门禁同样使用分类视图，酱料、生肉加工和糖霜不因数量备注复活。
