# 公开发布说明

GitHub 公开仓库：<https://github.com/CoirRaincoat/DietAgent>。

公开版本包含应用代码、Vue 前端、部署配置、2000 条菜谱、手写合成画像、合成测试和开发文档。界面与模型联调只使用合成资料。

## 私有资料边界

公开快照不包含以下本地资料：

- `dataset/user_profile/` 和 `dataset/evaluation/`：真实健康档案与原始对话。
- `evaluation/dialogues.json`：原始对话的本地人工标注。
- `tests/test_data.py`、`tests/test_real_data.py`、`tests/test_offline_replay.py`：依赖上述资料的测试，其中数据加载测试还含真实档案断言。
- `docs/problem.docx`、`docs/references/` 和 `prompt/`：本地题面、参考素材与工作提示。
- `.env`、虚拟环境、会话数据库、构建产物、浏览器截图和运行日志。

公开版 `evaluation/REAL_DATA_REPORT.md` 只保留汇总结果，不包含逐用户表。历史开发日志中的测试数量来自当时的完整本地环境；公开快照测试集合有所减少，不代表删除业务能力。

真实资料的验收脚本保留用于具备授权资料的本地环境，干净克隆默认不具备这些输入，不能直接复现私有数据验收。默认界面、合成测试与 Docker 部署均不依赖这些资料。

## 独立 Git 历史

原开发仓库的旧提交曾跟踪私有资料，不能通过仅删除当前文件后推送旧历史的方式公开。此次公开仓库采用独立初始提交；本地原仓库及其历史保留，不绑定公开远端。

本机公开副本位于原项目的 `artifacts/public-repo/`，仅此副本绑定公开远端；后续也可另行克隆公开仓库进行开发。不要在原含私有历史的仓库中添加公开远端或推送历史分支、标签。文档内早期提交标识属于本地开发记录，不属于公开快照的祖先提交。

`.gitignore` 已增加私有输入路径规则；它不会清除已经跟踪的文件或历史。后续发布前仍需检查暂存区及提交内容，避免加入真实档案、逐人验收结果或密钥。

## 启动与验证

先按 README 创建虚拟环境并安装依赖，在本地 `.env` 配置模型密钥。首次启动执行 `python -m evaluation.demo_start --build`；后续启动默认复用已有镜像。用户界面为 <http://localhost:8080>。

公开版默认测试使用合成对象、HTTP Mock 和菜谱 CSV，不发送真实健康资料。真实模型测试需要显式开启并配置本地密钥；仅允许使用合成资料。
