## 做法补全

六份草稿：红豆薏米粥、全麦欧包、手指小面包、南瓜吐司、天使白面包、吉野家牛肉饭。

- 粥：补在原末段混合之前，先把所列豆谷与水煮成粥体，不把原两分钟混合当成生豆谷已煮好。
- 普通面包：补发酵、排气/整形、末次醒发、烘烤、放凉；吐司另用吐司整形，已完成一次发酵的不重复添加。温度、时间和设备参数留待试做，不编成原数据。
- 牛肉饭：肉片回到炒香底料，加入原调味料继续烹饪，放回蔬菜并铺到原米饭上。不虚构焯水后留有可用水，不新增盐或辣椒，不声称复现品牌配方、健康或熟化安全。

补充明确标记“助手补全草稿”，原文保留。依赖食材须在原清单中，但这不是通用自然语言配料验证器或份量分配认证。手指小面包剩余蛋液的用途等仍未确认。
复杂酥皮、未使用馅料、药膳、原料不明、空步骤/编号缺失留作待核查，不用通用“煮熟”掩盖。有限扫描可能漏掉其他缺口。
