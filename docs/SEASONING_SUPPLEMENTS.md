# 家用基础调料与可选自调料汁（2026-10-06）

目的：不必为每种料汁单独购买成品酱，也不把“配方未明”统一判为辣或高钠。以下是公开参考衍生的**助手简化补充提案，待试做**，不是原2000配方、成品酱精确复刻或品牌成分认证。仅列明确配料，不编造用量、份数、营养数据或健康功效；没有自动接入默认鱼菜／修改原方。

## 建议先使用的四种组合

| 补充方案 | 明确配料 | 适用思路与边界 |

| 简化孜然烧烤调味粉 | 孜然粉、白胡椒粉、盐 | 干调味参考；不是任意商业烧烤粉，胡椒本身可能有辛感，不承诺完全无辛感 |

## 已知限制如何执行

1. 原菜和补充方案分开保存／展示。选择补充方案后，原调味料和新增配料的差异必须明确，不同时宣称仍是原配方；整道菜的主料、步骤、角色与所有硬要求仍要重新核验，不能只核这张表。
2. 生抽通常涉及大豆／小麦；蚝油涉及牡蛎，部分产品还有小麦等。以实际包装为准。例如[龟甲万日式照烧成分](https://www.kikkoman.com.sg/products/japanese-grill-teriyaki-sauce/)列含大豆／小麦的酱油；[李锦记美国照烧成分](https://usa.lkk.com/zh-hk/products/teriyaki-sauce)列含牡蛎的蚝油。未列花生不等于交叉接触已经排除。
3. 不辣方案不加辣椒、辣酱、芥末或品种未明椒类，不因成品名称猜辣味；胡椒／姜等辛感与个人耐受仍需另核。商业酱只给过敏提示不能代替明确过敏要求的核验。
4. 不含动物成分的提案仅为文字层面的纯素参考，不代替实际品牌核对；含蚝油的方案不能靠“生抽替代蚝油”自动称等价或保留原菜身份。
5. 出现盐／酱油只说明有含钠来源，实际用量、整菜份数及全天摄入未知时不宣称高钠／低钠、护心或降压效果。含糖方案也不宣称适合控糖。
6. 不把沙茶、XO、咖喱、火锅底料、美乃滋等一律简化为生抽／蚝油；不能说明具体配方的复合料，保留待核或提供明确另行命名的提案，不猜漏过敏原。
