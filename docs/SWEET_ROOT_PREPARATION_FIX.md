## 本轮解决什么

源记录的午餐、晚餐、清淡或健康标签不能让甜点占据普通正餐位置。`app/domain/source_preparation.py` 准备证据 v4 联合配料与制作过程，有限识别：加糖糯米粉揉圆裹芝麻油炸；蒸根茎淋糖浆；根茎加糖搅打配红枣蒸制；蜂蜜桂花酱刷根茎；蒸根茎直接蘸糖；银耳水果加糖水煮/蒸盅。

不是按菜名拒绝所有南瓜、山药或蜂蜜菜。咸味调料、肉类和明确米饭/面食等对照保留；单纯原味蒸南瓜、无加糖山药、少量蜂蜜烤南瓜、馒头、糯米饭和肉馅糯米球不因本轮规则被排除。上述保护是有限制作证据边界，不是医疗、食品安全或全库分类保证。

原料表写“糯米”而制作步骤写“糯米粉”时保留源差异，不能悄悄改原料；配料表未写水但步骤明确“加入清水”的银耳瓜盅，也不能因漏列水忽略甜羹证据。没有删糖、改配方或生成新菜。

已有统一门禁仍覆盖菜单、替换建议、旧角色元数据、HTTP/SSE 与旧菜单解释。普通继续不重新排列菜单，局部换菜保护其它位置。独立 `main_meal_findings` oracle v11 使用另外审核的源反例，不导入生产分类或健康评分，不接受返回状态自证合格。
